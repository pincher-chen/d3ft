# Electronic bands, sampled-gap transfer and deformation response

Run `python script/plot_figure_bands_and_transfer.py --verify-data` from this folder, or use `--output-dir /path/to/new/output` to preserve the checked-in PDF.

All data used by the script are in `data/`; `SOURCES.json` verifies the published copies. No DFT job is launched. Replotting changes presentation only. The response-design overview and record index describe the scope and negative results.

Collection: **response-design**. The folder and entry filenames describe the function, independently of manuscript figure numbering.
