# Release 2026-10-13

This is a curated code/data release, not an additional parameter-tuning round. The current corrected-phase source includes the Na NLCC repair; exact pre-repair and PH-prefix solver versions are retained. Original current development Python code is archived separately. Generic legacy CLI defaults are distinguished from the explicit paper protocol.

Six physical reproduction cases include structure, UPF, accepted endpoint metadata, compact posterior eigenvalues and original QE density/spectra. Figures1–6 and FigureS1 have standalone local-data scripts. Figure4 is the five-system path-band comparison; the GaAs mechanism/development panel is Figure5, cost/scaling Figure6.

Portable drivers change paths only. Tests retain initial packaging failures and document the version/fixture/sharding fixes. Manuscripts and running allocations were not modified. Full wavefunction data are left in the original archives; Git contains compact analysis data and cold-start regeneration scripts.
