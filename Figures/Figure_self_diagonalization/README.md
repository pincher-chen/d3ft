# Hamiltonian self-diagonalization and commutator

Main text, Section 4.2. Al 4-atom fcc cell, Γ point only, shared norm-conserving Hamiltonian, 26 bands, seed 1101 (JRystal benchmark). Units: Ha.

| Panel | Content |
|---|---|
| (a) | h at steps 0, 100, 1000, 4000 for this work (top row) and QR/idempotent–Adam (bottom row, "QR/Adam"). States sorted by h_ii; upper triangle + diagonal = Re h_ij, lower triangle = Im h_ij. Colormap RdBu_r, TwoSlopeNorm(−1, 0, 1) Ha. |

## data/
- `raw_hamiltonian/<arm>_<step>.npz` — original archived snapshots (`hamiltonian_Ha` complex 1×26×26, `occupations` 1×1×26, `temperature_Ha`). `method` = this work, `qr` = QR/Adam. Steps of this work after 1000 come from the second run segment (step = 1000 + step within segment).
- `fig1_Al_H_commutator.csv` — commutator norm at the sampled steps (column `commutator_Frobenius_Ha`).
- `origin_csv/` — **generated by the script**: plain CSV for Origin (`a_<Arm>_step<S>_plotted|Re|Im.csv` 26×26 matrices without header; `a_<Arm>_step<S>_states.csv`; `b_commutator_sparse.csv`).
- `SOURCES.json` — original path and SHA-256 of every copied file.
- Pending: `fig1_dense_trace.csv` (per-step commutator from a verified deterministic replay). When present, panel (b) is drawn from it automatically.

## script/
`python script/plot_figure_self_diagonalization.py` → writes `origin_csv/`, `Figure_self_diagonalization.pdf`, `Figure_self_diagonalization.png`.

Collection: **ground-state**. The folder and entry filenames describe the function, independently of manuscript figure numbering.
These are retained ground-state benchmark results; they are not response-design experiment data. The exact earlier tree remains available at tag `v1.0`.
